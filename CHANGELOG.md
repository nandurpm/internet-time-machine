# Changelog

All notable changes to this project are documented in this file.

## [0.1.0] - 2026-08-24

The initial release adds a provenance-aware network monitoring dashboard, validated endpoint profiles, a separate SQLite persistence layer, direct HTTP/DNS measurements, safe packet-loss handling, endpoint-local incident detection, charts, filtered exports, and authenticated rate-limited scheduling. The release also includes clearly marked simulated demo data and automated coverage for the core safety and correctness behaviors.
